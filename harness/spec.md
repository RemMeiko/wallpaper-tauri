# 需求规格: Wallhaven 壁纸工具功能补齐

## 概述

Wallhaven 壁纸工具是一个基于 Tauri + React 的桌面应用，面向 Windows 用户，提供壁纸搜索、下载、本地管理和自动轮换功能。当前版本已完成 UI 深色主题定制和搜索+下载核心链路，但功能较为基础（仅单页搜索和手动下载）。

本次迭代的目标是将其从"搜索下载工具"升级为"完整的壁纸管理工具"，补齐多页加载、本地壁纸库浏览、设为桌面壁纸、配置持久化、自动轮换等关键功能，并通过 Tab 布局重组界面结构。

用户群体为希望便捷管理桌面壁纸的 Windows 用户，核心价值是一站式完成壁纸发现、收藏和自动切换。

## 核心功能

1. **搜索结果多页加载**: 突破当前单页 24 张的限制，让用户获取更多搜索结果
   - 用户场景: 作为用户，我搜索壁纸后可以点击"加载更多"获取下一页结果，无需重新搜索
   - 验收标准:
     - 搜索完成后页面底部显示"加载更多"按钮
     - 点击按钮后追加下一页结果到现有列表（不清空已有结果）
     - 加载过程中按钮显示 loading 状态
     - 无更多结果时按钮禁用或隐藏

2. **前端 Tab 布局**: 将应用重组为三个功能区域，清晰分离搜索、本地库和设置
   - 用户场景: 作为用户，我可以通过顶部 Tab 在"搜索壁纸"、"本地壁纸"、"设置"之间切换
   - 验收标准:
     - 应用顶部（TitleBar 下方）显示三个 Tab：搜索壁纸 / 本地壁纸 / 设置
     - 切换 Tab 时内容区域对应变化
     - 默认激活"搜索壁纸" Tab
     - 使用已有的 shadcn/ui Tabs 组件，保持深色主题风格一致

3. **本地壁纸库管理**: 浏览和管理已下载到本地的壁纸文件
   - 用户场景: 作为用户，我可以在"本地壁纸" Tab 中看到指定目录下所有图片的缩略图网格
   - 验收标准:
     - Rust 后端提供扫描指定目录图片文件（jpg/png/bmp/webp）的命令
     - 前端以网格形式展示本地图片缩略图（复用 WallpaperCard 风格）
     - 本地图片通过 Tauri asset protocol 或 convertFileSrc() 正确显示
     - 支持选中图片（单选）

4. **设为桌面壁纸**: 将搜索结果或本地图片设为 Windows 桌面壁纸
   - 用户场景: 作为用户，我可以在搜索页下载壁纸后直接设为桌面壁纸，也可以在本地库中选中图片设为壁纸
   - 验收标准:
     - Rust 后端提供 set_wallpaper 命令，调用 Windows SystemParametersInfoW API
     - 搜索页下载完成后提供"设为壁纸"操作入口
     - 本地壁纸页选中图片后提供"设为壁纸"按钮
     - 设置成功后 toast 提示，桌面壁纸实际变更

5. **配置持久化**: 保存用户偏好设置，应用重启后恢复
   - 用户场景: 作为用户，我设置的下载目录、轮换参数等在重启应用后仍然保留
   - 验收标准:
     - Rust 后端提供 load_settings / save_settings 命令
     - 配置存储在 ~/.wallpaper_app/settings.json
     - 配置项包含：下载目录路径、轮换开关、轮换间隔（分钟）、轮换模式（随机/顺序）
     - 应用启动时自动加载配置
     - 设置页修改后自动保存

6. **壁纸自动轮换**: 定时自动切换桌面壁纸
   - 用户场景: 作为用户，我可以开启自动轮换，应用会按设定间隔从本地壁纸库中自动切换桌面壁纸
   - 验收标准:
     - 设置页提供轮换开关、间隔设置（分钟）、模式选择（随机/顺序）
     - 开启后 Rust 后端启动定时器，按间隔从本地壁纸目录选取图片并设为壁纸
     - 前端显示轮换状态（是否运行中、下次切换时间）
     - 关闭轮换后定时器停止

## 技术架构

- 语言/框架: React 18 + TypeScript 前端，Rust Tauri v2 后端，Tailwind CSS v4 + shadcn/ui (base-nova) 组件库
- 关键模式:
  - Tauri command 模式：前端通过 invoke() 调用 Rust 后端命令
  - 本地文件访问：使用 Tauri asset protocol 将本地文件路径转为前端可用的 URL
  - Windows API 调用：Rust 通过 windows-sys 或 winapi crate 调用 SystemParametersInfoW
  - 状态管理：React useState + 组件 props 传递（保持现有模式）
- 依赖:
  - 已有：reqwest, serde, tauri-plugin-dialog, tauri-plugin-fs, @tauri-apps/api
  - 新增（Rust）：windows-sys 或 winapi（用于设置壁纸 API）
  - 新增（前端）：无额外依赖，使用已有 shadcn/ui 组件

## 不在范围内

- macOS / Linux 壁纸设置支持（仅 Windows）
- Wallhaven API key 认证（仅使用公开 API）
- 壁纸收藏/标签/分类管理
- 图片编辑或裁剪功能
- 多显示器壁纸独立设置
- 系统托盘常驻 / 开机自启
- 壁纸来源扩展（仅 Wallhaven）

## 风险和约束

- **Windows API 调用**: SystemParametersInfoW 需要传入绝对路径的 BMP/JPG 文件，需确认对 PNG/WebP 格式的兼容性（Windows 10+ 通常支持 JPG，但 WebP 可能需要转换）
- **Tauri asset protocol 配置**: 本地文件在前端展示需要正确配置 Tauri 的 security scope 或使用 convertFileSrc()，配置不当会导致图片无法加载
- **UI 风格一致性约束**: 所有新增 UI 必须保持现有蓝色深色主题和动画风格，不能引入视觉断裂
- **轮换定时器生命周期**: 需要处理应用最小化/后台运行时定时器的行为，以及应用退出后轮换停止的问题
- **大目录性能**: 本地壁纸目录如果包含大量图片（数百张），缩略图加载需要考虑性能（懒加载）
